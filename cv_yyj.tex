\begin{rSection}{数字 IC / RTL 项目经历}
  \begin{rSubsection}{ASOCA2：双可寻址近存图加速 ASIC}{2022年11月 -- 2023年12月}
    {The University of Edinburgh}{180 nm ASIC 原型}
    \item 迭代实现并验证 CTRL、BUF、ONECON、LOI、COMP 等数字模块，覆盖指令控制 FSM、数据缓冲、优先匹配、状态掩码及比较 datapath，并参与顶层集成
    \item 主导 directed system-level testbench 与验证环境；56 个 testcases 覆盖十类指令及持续并发压力，VCS 中 48 个带结果检查的初始化/功能用例全部通过
    \item 完成 hypercluster 级 scan-chain 集成与 backend verification，参与综合和流片交付；搭建硅后测试流程并排查数字 I/O/scan 边界信号衰减
  \end{rSubsection}

  \begin{rSubsection}{ASOCA3：复杂加速器处理核 RTL}{2024年1月 -- 至今}
    {The University of Edinburgh}{FPGA accelerator system}
    \item 独立设计 supercluster 处理核、六级执行流水及 RTL 控制结构，包含 instruction assembly/decode、memory、register read/writeback 与 NoC-facing read/write stages
    \item 实现分布式 valid/ready 流控、pipeline registers、冒险检查、stall/flush、16 项双读单写寄存器堆，以及流水线与 RECONS 反馈路径间的 fixed-priority arbitration
    \item 实现复合/谓词指令 RECONS 引擎与 packet reconstruction，定义 44-bit ASOCA64 flit 及 SC-side handshake；最终 NoC/PCIe 与顶层集成为团队系统背景
  \end{rSubsection}

  \newpage

  \begin{rSubsection}{ENGINE：可参数化双可寻址存储器 RTL}{2024年 -- 2025年}
    {The University of Edinburgh}{独立设计与实现}
    \item 独立完成 BRAM 双可寻址存储器的架构、RTL 与 FPGA implementation；实现 BROADCAST 译码、并行 RAMB 存储和 CARU/TURBO 内容匹配路径
    \item 在 Virtex-7 上以 4 BRAM36、683 LUT、248 FF 实现 $8\times512\times36$ 配置，达到 129.27 MHz 与 100\% BRAM 存储效率，并在 Versal、Zynq、Virtex 系列验证
  \end{rSubsection}

  \begin{rSubsection}{AIDE：自动化设计流与定制验证环境}{2025年11月 -- 至今}
    {The University of Edinburgh}{博士子课题}
    \item 独立开发 Makefile 自动化 flow、ASOCA64 assembler/simulator 与 test-vector generation，扩展 Python reference model 生成 RTL expected results
    \item 主导轻量化、UVM-inspired compliance environment，实现 input sequencer、output monitor、ID-based scoreboard、assertion capture、functional coverage 与仿真报告
  \end{rSubsection}

  \begin{rSubsection}{CoNM：四级流水 RV32I 处理器 RTL}{2021年3月 -- 2021年6月}
    {同济大学}{本科毕业设计}
    \item 使用 Verilog 完成带静态分支预测的四级流水 RV32I CPU 内核设计
    \item 在 PYNQ-Z1 FPGA 开发板完成综合实现与功能验证
  \end{rSubsection}
